# my-master-degree-work
Permafrost Study in Yakutia

Web-SIG interactif dédié à l'analyse spatio-temporelle des feux et du pergélisol en République de Sakha (Iakoutie), Russie.

Mémoire

Analyse spatio-temporelle des feux et du permafrost en Yakoutie Master Géomatique et Modélisation Spatiale — Aix-Marseille Université Auteure : Lucia Conforte Houéfa BOKO Direction : Pr. Sébastien GADAL — 2025-2026

Contenu
Carte interactive (Leaflet.js) centrée sur la République de Sakha
Zone d'étude intégrée (limite administrative GADM)
Analyse pergélisol & feux (couche intégrée)
5 graphiques (Chart.js) basés sur une série temporelle réelle 2001–2026 : température de surface, températures du sol, anomalies de végétation, albédo, couverture neigeuse
Déploiement

Ce site est un fichier HTML autonome (permafrost_study_yakutia(3).html), sans backend ni base de données — toutes les données sont intégrées directement dans la page. Publié via GitHub Pages.

Technologies

Leaflet.js · Chart.js · HTML / CSS / JavaScript
